This is a research prototype for an unpublished study (Paper 2; authors Appiah, Opoku and Asare, Kumasi Technical University). Its results are not yet published or peer-reviewed. In GitHub Actions, manually dispatch Paper 2 G3 validation for ARM measurements; when it reports prototype-complete: replay pending, manually dispatch Paper 2 G3 deterministic replay with source_run_id set to that ARM run ID. Only the replay gather report determines G3 agreement, after reviewing its evidence. Both workflows use workflow_dispatch only; no workflow is dispatched by exporting or publishing this bundle.
